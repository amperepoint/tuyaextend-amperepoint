## Important

Wallbox PRIME uses the built-in **AmperePoint Local (LAN)** connection. Compatible
control DPs enable start/stop, current control and the HA planner independently
of firmware version. A separate Tuya Local installation is not required; see the
language manuals above for setup, supported functions and current limits.

AmperePoint does not replace device pairing. Q Series can use the official
Home Assistant Tuya integration; PRIME uses the built-in LAN connection.
The shared panel is named **Ampere Point - Tuya dashboard**.

AmperePoint nie zastępuje parowania urządzenia. Q Series może korzystać z
oficjalnej integracji Tuya, a PRIME korzysta z wbudowanego połączenia LAN.
Zgodne DP sterujące udostępniają start/stop, zmianę prądu i planer HA niezależnie
od numeru firmware. Osobny dodatek Tuya Local nie jest wymagany.
Nazwa wspólnego panelu: **Ampere Point - Tuya dashboard**.
